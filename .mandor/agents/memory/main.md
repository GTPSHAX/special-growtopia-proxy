# specialproxy-core Memory

## Proxy Module (include/specialproxy/proxy/)
- Core = proxy Growtopia ala luckyproxy-android: client GT <-> [proxy listen 17099] <-> [proxy connect] <-> server GT.
- **Konsep API publik**: core = lib DENGAN entry point. Consumer cukup `spx::proxy_start(config)` + `proxy_stop()` + toggler (`proxy_toggle("intercept_redirect"/"verbose")`) + `proxy_message_clients(text)` + `spx::proxy_set_upstream(server, port)` / `spx::proxy_upstream()`. Consumer TIDAK merakit host/session di loader. `ProxyService` = detail internal facade (src/proxy/Core.cpp: background thread + hooks logging verbose).
- `ProxyService`: dual host (client listen + server connect), `poll(timeout)` non-blocking / `run()` blocking / `stop()` atomic. Forward raw dua arah; hook `on_client_packet`/`on_server_packet` return false = drop (hook kirim modifikasi sendiri via `send_to_client`/`send_to_server`/`send_to_all_clients`). `on_client_connected`/`on_server_connected`/`on_disconnect`/`on_redirect`.
- **Intercept OnSendToServer (default ON, toggle "intercept_redirect")**: OnSendToServer dari server TIDAK diteruskan mentah. Proxy parse typed, catat real address+port ke `redirects_by_client_ip_[client ip]`, update session target, rewrite address->config.redirect_address + port->listen_port, token/user/door/uuid/login_mode/username asli tetap. Client reconnect ke proxy -> session baru dipakai real target (key IP, sekali pakai). Smoke proof: server 17091 -> client lihat port 17099.
- `Session` = {client peer, server peer, id, server_address, server_port}. Mapping dua unordered_map keyed ENetPeer* (rehash aman utk pointer). Session server-peer dimapping saat connect request (sebelum Connect event datang). Peer disconnect dari sisi lain memicu teardown dua sisi.
- Config `ProxyConfig{listen_port, server_address, server_port, max_sessions, redirect_address, control_port}`. `control_port` = UDP loopback untuk update upstream dari proses lain, 0 = mati (default).
- Facade proxy_start memanggil net::initialize() sendiri (ENet wajib init sebelum create host), proxy_stop memanggil deinitialize. Jangan lupa ini kalau ubah facade.
- Naming gotcha: dari namespace spx (atau spx::proxy), simbol sibling namespace (spx::packet, spx::proxy::game) TIDAK ketemu unqualified — wajib qualified `packet::X`, `proxy::ProxyConfig`.
